# Proxmox vProxy (emc-vProxy-SPP) — Prerequisites Guide

Cleaned-up, de-duplicated version of the trial-and-error bash history, reordered into a working sequence. Run everything as the `admin` user with `sudo` — do **not** switch to a root shell (`sudo su`).

## 0. Minimum VM requirements for the proxy

This mirrors the external VM Direct Engine sizing used for VM/NAS protection engines.

| Resource | Minimum requirement |
|---|---|
| CPU | 4 vCPU @ 2 GHz (4 virtual sockets, 1 core per socket) |
| Memory | 8 GB RAM |
| Disk 1 | 59 GB |
| Disk 2 | 98 GB |
| Network | One vmxnet3 NIC with one port |
| SCSI controller | 4 (maximum) |
| Internet Protocol | IPv4 only or IPv6 only — Linux package-based components support IPv4 only |

Notes:
* These are minimums — the installer fails to deploy on a host below these values, but will run fine on a host with more resources.
* Up to 25 external VM Direct Engines are supported per vCenter server; 7 is the recommended number.
* For Linux install-package deployments specifically (as used here), every component the proxy communicates with must use IPv4 only, regardless of any IPv6 support elsewhere in the environment.
* Dedicate the host to the protection engine only — do not run other applications or nonsystem services on it.

## 1. Confirm the `admin` user and group

```bash
id admin
groups admin
```

Expected: `admin` exists and is a member of the `admin` group (required by the installer's pre-requisites notice).

## 2. Install base OS packages

```bash
sudo dnf install -y curl firewalld bind-utils iputils
sudo systemctl enable --now firewalld
```

* `curl` — downloads/API calls
* `firewalld` — firewall management expected by the config checker
* `bind-utils` — provides `nslookup`
* `iputils` — provides `ping`

## 3. Fix the missing `libcrypt.so.1` dependency

Rocky Linux 9 ships `libxcrypt` instead of the legacy glibc `libcrypt`, which breaks the `emc-vProxy` RPM dependency check.

```bash
sudo dnf install -y libxcrypt-compat
```

## 4. Install Docker CE — pinned to 28.x

Dell's PPDM 20.2 Deployment Guide states Docker 29.x+ is **not supported** for NAS, PowerMax, or archive-to-object proxy workloads, so pin to the 28.x line.

```bash
# Add the official Docker repo (not available in default Rocky repos)
sudo dnf -y install dnf-plugins-core
sudo dnf config-manager --add-repo https://download.docker.com/linux/rhel/docker-ce.repo

# List available 28.x builds and note the exact version string
sudo dnf list docker-ce --showduplicates | sort -r

# Install the pinned 28.x build (replace X.X-1.el9 with the version found above)
sudo dnf install -y \
  docker-ce-3:28.X.X-1.el9 \
  docker-ce-cli-1:28.X.X-1.el9 \
  containerd.io \
  docker-buildx-plugin \
  docker-compose-plugin

sudo systemctl enable --now docker
docker --version
```

Lock the version so a future `dnf update` doesn't silently pull in 29.x:

```bash
sudo dnf install -y python3-dnf-plugin-versionlock
sudo dnf versionlock add docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
```

## 6. (Optional) Mount a dedicated XFS data partition

If using a separate disk/partition (e.g. `/dev/sdb1`) for proxy data, mount it permanently before running the installer.

```bash
sudo mkdir -p /data1
sudo blkid /dev/sdb1    # note the UUID
```

Add to `/etc/fstab` (replace the UUID with the one from `blkid`):

```
UUID=1a2b3c4d-5e6f-7890-abcd-ef1234567890  /data1  xfs  defaults  0  0
```

Test and verify:

```bash
sudo mount -a
df -h /data1
```

## 7. Extract the install package

```bash
tar xzfv emc-vProxy-SPP-20.4.0.0-1-SNAPSHOT-pack.tar.gz
cd emc-vProxy-SPP
```

## 8. Run the installer

Run as `admin` with `sudo` (do **not** use `sudo su` — the installer needs root privileges for a single command, not an interactive root shell; running as plain `admin` without `sudo` causes the `mkdir /usr/local/vproxy: Keine Berechtigung` permission error seen earlier).

**Interactive mode:**
```bash
sudo ./installSPP.sh --path=/home/admin/emc-vProxy-SPP/pkg/
```

**Non-interactive mode** (password `Password123!`, protection type Proxmox):
```bash
echo 'Password123!' > /home/admin/.ppdm_pass && chmod 600 /home/admin/.ppdm_pass

sudo ./installSPP.sh \
  --path=/home/admin/emc-vProxy-SPP/pkg/ \
  --supported-protection-types=Proxmox \
  --proxy-mgmt-ip=192.168.1.108 \
  --proxy-password=Password123! \
  --ppdm-password-file=/home/admin/.ppdm_pass \
  --is-multivlan-enabled=no \
  --proxmox-inventory-source-id=a15b21f0-c188-53fe-81d1-3d22bb7314ff
```

## 9. Post-install sanity checks

```bash
docker --version
rpm -q erlang rabbitmq-server
systemctl status docker rabbitmq-server firewalld

```
